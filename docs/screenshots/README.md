# Screenshot Capture Guide

Capture these for portfolio and README updates:

1. `landing-demo.png`
   - Hero card, metric cards, and a completed live demo response.
2. `support-agent-trace.png`
   - Support Agent page with answer, citations, and trace panel visible.
3. `eval-studio.png`
   - Evaluation Studio summary cards and case table after running evals.
4. `escalation-queue.png`
   - At least one unresolved escalation plus "Create Knowledge Article" form.

Tips:
- Use consistent browser width across captures.
- Blur or hide sensitive URLs/tokens if present.
- Re-capture after major UI or metric changes.
